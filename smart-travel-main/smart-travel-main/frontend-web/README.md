# frontend-web

React frontend skeleton for Smart Travel.

## Current Scope (W2 close)
- Home route: `/`
- Search route: `/search`
- UI skeleton: search filters + result cards

## Run locally
1. Install dependencies:
	- `npm install`
2. Start dev server:
	- `npm run dev`
3. Build production bundle:
	- `npm run build`

## Key files
- `src/pages/HomePage.jsx`
- `src/pages/SearchPage.jsx`
- `src/ui/PlaceCard.jsx`
- `src/App.jsx`
